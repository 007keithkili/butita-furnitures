# Butita Furnitures — Website 🪑

Official website for **Butita Furnitures**, a handcrafted furniture works business.

## Pages
- **index.html** — Home page (hero, what we do, how it works, founder story, customer voices)
- **services.html** — Full catalogue (Resting Area, Bedroom, Kitchen, Shops & Display + extra services)
- **logo.svg** — Brand logo

## Features
- 🌓 Light & dark theme toggle (saved to localStorage, respects system preference)
- 📱 Responsive layout (desktop, tablet, mobile)
- 💬 WhatsApp + call contact buttons (+254 725 894 430)
- 🖼️ Product gallery with categories, prices & hover effects

## Usage
Open `index.html` in any browser, or deploy via **GitHub Pages**:
1. Settings → Pages → Source: `main` branch, `/` root
2. Site available at `https://<username>.github.io/butita-furnitures/`

## Local Edits
Product images are hosted on Unsplash — replace the image URLs with real photos of your own work when available.
